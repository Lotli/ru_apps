# RU apps
Список пакетов российских приложений для настройки подписки Happ в 3x-ui

## Как добавить списов в 3x-ui
*Настройки панели > Подписка > Happ > Сетевые настройки и TUN*

**Прокси для приложений (Android):** Обход (исключить выбранные приложения)\
**Пакеты приложений Android:** Вставьте содержимое файла [list_android.txt](https://github.com/Lotli/ru_apps/blob/main/list_android.txt)

## Как составлялся список
### Приложения от разработчиков из [списка от RKS global](https://files.rks.global/russian_apps_search_for_vpn_ru.pdf)
